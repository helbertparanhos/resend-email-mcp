# Contributing

Contributions are welcome!

1. **Fork** the repo and create a branch from `main`.
2. Make your change. For a new tool, follow the existing `defineTool` pattern in `src/tools/`
   (one file per resource group, Zod schema, `mutating` flag, actionable errors).
3. `npm install && npm run build` must pass clean (TypeScript strict).
4. Commit using [Conventional Commits](https://www.conventionalcommits.org/)
   (`feat:`, `fix:`, `docs:`, `chore:` …).
5. Open a Pull Request describing the change.

## Reporting bugs / requesting features

Use GitHub Issues with the provided templates.
